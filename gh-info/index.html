me.oriz.in — an engineer's instrument bench

A public, static personal dashboard for Chirag Singhal — a backend & AI systems engineer. This is the "about" page for the project. The live site is the tool itself.

Open the live app → Source on GitHub llms.txt

What it is

me.oriz.in aggregates and instruments a working life into one public dashboard: professional portfolio and open-source work, a full media library, live coding activity, and personal life stats. Everything is public and free — no ads, no signup wall, no tracking.

Key features

  • Work — career, projects, skills, education, certifications, open source, and writing.
  • Library — music, movies, TV, anime, manga, books, gaming, podcasts, and a live activity feed.
  • Me — now, story, timeline, values, goals, gear, philosophy, coding activity, journal, health, and an AI digital twin.
  • Live readouts — WakaTime coding time, GitHub repos, Last.fm scrobbles, Trakt films, Discord presence.
  • Data from ~30 APIs pulled at build time into static JSON — no runtime backend.

Tech

  • Client-only Astro (output: static) + React 19 islands + Tailwind.
  • g4f AI via @chirag127/oz-ai — the digital twin and Ask features run 100% in the browser, no server key.
  • PWA-installable — offline static shell; live data is always network-only, never stale.
  • 100% in-browser, no upload, no signup — optional oriz SSO exists but gates nothing public.
This is the project info page. To actually use the dashboard, go to me.oriz.in.
